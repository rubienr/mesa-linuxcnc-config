# Current hardware-documentation instructions

These rules apply to current machine evidence and migration records.

- Use the README index and open only topic files relevant to the task.
- Preserve the status vocabulary: **Confirmed**, **Legacy-derived**, and **To
  verify**. State provenance for every new technical fact.
- A datasheet for a related model does not override a physical nameplate,
  measurement, or confirmed installed-device identity.
- Keep unresolved work in `TODO.md`; do not present an unchecked item as a
  settled design decision.
- Preserve raw capture data. Generated register tables must be reproducible
  from their JSON source and renderer.
- When consulting
  `datasheets/huanyang-hy-series-instruction-67-numbered-pages-ocr.txt`, use a
  targeted lookup for the parameter or phrase at issue; do not read or load the
  OCR transcript wholesale.
- Do not provide or perform an energized-mains inspection procedure.
