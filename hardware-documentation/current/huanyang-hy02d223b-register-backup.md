## Capture tool

[`tools/read-huanyang-vfd.py`](tools/read-huanyang-vfd.py) is deliberately read-only: its request builder contains only function `0x01`. Do not replace it with `hy_vfd --regdump` for forensic captures, because the normal `hy_vfd` loop subsequently transmits control and frequency commands.
