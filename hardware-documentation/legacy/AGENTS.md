# Legacy hardware-documentation instructions

This subtree is forensic evidence from the BeagleBone/Panther/Machinekit
installation, not the current machine source of truth.

- Do not modernize, normalize, or repair historical files unless explicitly
  asked; apparent mistakes may be evidence.
- Do not copy a legacy value into the current configuration without recording
  its provenance and marking it unverified until physically confirmed.
- Prefer additions to current documentation over edits that reinterpret the
  archive.
- Preserve original formats, backups, and schematic artifacts.
